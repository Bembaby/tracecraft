## Coherent phases

1. Connect private profile, diagnostic, skills, notebook, reviews and daily recommendations. Migrate old progress without losing existing records.
2. Add reviewed Python/fitness-SQL packs and backend/auth scenarios, with real runtime tests and equivalent SQL accepted.
3. Connect incident investigations, own-project explanations, interviews and walking controls. Label authored choice checking and written self-review separately from execution.
4. Keep specialist tracks available through assessment and clear next project steps. Full Spring/MySQL execution, real infrastructure incidents, paid AI feedback and inference-server integrations are not represented as working browser features.

## Release gates

Phases 1 through 3 are implemented. `npm run check`, `npm test` and `npm run build` pass: 576 tests, zero failures or skips. The suite includes actual CPython, vendored SQLite, retained browser Java, private-state migration/backup round trips, assistance and delayed-retention rules, independent answer keys and deliberate-bug regressions. Six independent pack/state/interface critiques were incorporated. New content is original and versioned; task and variation links are validated.

Authenticated loopback observations use real Better Auth, a synthetic email sink, in-memory account storage and production CSP. They cover actual Python and SQLite checks, prediction gating, diagnostic skip/resume, notebook draft reload, profile persistence, reviewed account save/restore, scenario failure/retry, speech controls, optional question clock pause/reload, and desktop/390px layouts. See [QA](QA.md) for precise evidence and publication status. Source push and PR merge remain outside this increment.

## Remaining scope and concrete continuation

- Specialist tracks have authored placement and links to the existing project path. Full frontend/mobile applications, inference-server labs and service-specific advanced tracks remain planned. Next: author an original backend feature assignment with an explicit request/DTO/ownership/transaction contract and externally runnable integration-test fixtures, then connect its evidence to the existing project milestones.
- SQLite checks establish SQLite behavior. Full Spring/MySQL projects still run in a separate development environment; browser Java provides its documented console subset, not Spring or a complete JDK.
- Scenarios check authored choices and expose evidence on request. Their writing and communication rubrics are self-assessment. No LLM grader, live infrastructure incident or conversational AI service was added.
- Walking mode offers browser read-aloud and text or device dictation. It does not capture audio, transcribe speech, or automatically assess spoken answers. Browser voice availability varies.
- Retention requires configurable distinct variations, separate practice days and delay. Skills without enough reviewed variations stay below the retention criterion; same-day repeats, confidence, read marks and aided answers do not establish retention.
- Required email sign-in and initial Python asset download still need their configured network services. Existing drafts and reviewed backups are preserved; this is not an offline-first account system.
